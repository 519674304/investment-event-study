# 研究页面视觉设计

状态：用户已确认  
确认日期：2026-08-13

## 设计目标

研究页面以 K 线为视觉中心，让用户直接观察消息发生在股价的什么位置。页面只负责呈现事实位置和原始信息，不自动生成领先、滞后、利多或利空判断。

## 页面结构

采用全宽图表型布局，不保留常驻左侧对象栏。页面从上到下依次为：

1. 研究对象搜索、选择及最近研究对象快捷入口。
2. 当前对象、起止日期、日/周/月周期、获取行情和补录事件操作。
3. 全宽 K 线与成交量图。
4. 事件分类及标签筛选。
5. 按真实发布日期倒序排列的完整事件详情。

```text
┌──────────────────────────────────────────────────────────────┐
│ 行情与事件研究                                               │
│ [搜索/选择对象________▼]  [生猪养殖] [牧原股份] [温氏股份]  │
├──────────────────────────────────────────────────────────────┤
│ 生猪养殖 884275                                              │
│ [开始日期]—[结束日期] [日K][周K][月K] [获取行情] [补录事件] │
├──────────────────────────────────────────────────────────────┤
│                         K 线图                               │
│       ▲猪价上涨      ▲母猪数据          ▲3条事件             │
│                         成交量                               │
├──────────────────────────────────────────────────────────────┤
│ 事件筛选：[全部] [猪价] [供给] [需求] [政策] [自定义标签]   │
├──────────────────────────────────────────────────────────────┤
│ 2026-08-09  居民猪肉价格环比上涨                    [编辑]   │
│ 摘要……  猪价｜国家统计局｜[查看原文]                       │
└──────────────────────────────────────────────────────────────┘
```

## 图上事件标记

- K 线图上直接显示事件短标题，例如“猪价上涨”“母猪存栏”。
- 同一根 K 线对应多条事件时显示聚合标记，例如“3 条事件”，避免互相遮挡。
- 悬停标记显示真实发布日期、完整标题、来源及简要摘要。
- 点击标记后，页面滚动到下方对应事件并高亮。
- 点击下方事件后，图表定位并高亮对应 K 线和标记。
- 周末、节假日或停牌日事件映射到此前最近一根 K 线，但标记提示和下方详情继续显示真实发布日期。
- 日 K、周 K、月 K 均显示事件；周期切换只改变投影位置，不修改事件记录。

## 事件详情

完整标题、摘要、来源、原文链接、分类和标签统一位于图表下方，不放入常驻侧栏，也不把长文本永久展开在图中。来源链接只作为持久化信息展示，不检查链接是否仍然有效。

## 当前原型边界

本次确认的是主页面信息架构、图上标记方式和图下详情位置。颜色、字号、间距、事件标记的最终形状以及搜索和补录弹窗细节，可在可运行原型中继续调整，但不得改变上述主次结构。
