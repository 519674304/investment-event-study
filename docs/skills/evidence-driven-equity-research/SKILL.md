# 证据驱动型企业投研

产出高信息密度、可审计的公司分析。依据可验证证据建立从经营事实到估值的因果链，不模仿券商研报的语气和表演性结构。

## 必须读取的参考文件

- 完整分析公司时，读取 [references/research-workflow.md](references/research-workflow.md)，执行其中的证据标签、三项独立分析、估值流程和更新规则。
- 生成或修改报告时，读取 [references/output-template.md](references/output-template.md)，遵守章节边界和语言约束。
- 只有当政策会实质影响公司的核心价值变量时，才读取 [references/policy-transmission.md](references/policy-transmission.md)；否则跳过政策分析。

## 核心流程

```text
明确研究问题 → 建立五类事实底座 → 绘制当前运行机制
→ 分析盈利结构 → 分析成本结构 → 分析风险结构
→ 综合三者传导关系 → 压缩为核心价值变量
→ 反推当前价格隐含预期 → 检验竞争性解释
→ 分析行业和宏观因素 → 条件性分析政策传导
→ 建立情景和估值区间 → 给出置信度、证伪条件、跟踪指标和工作假设
```

不得先确定目标价，再倒推支持目标价的理由。

## 不可违反的边界

### 分离三项公司分析

必须分别设置三个独立章节：

1. **盈利结构**：谁付钱，哪些产品和客户贡献收入，哪些业务贡献利润和现金流，增长由什么驱动。
2. **成本结构**：钱主要花在哪里，哪些成本固定或可变，各项主要支出由什么驱动，如何影响利润率和现金流。
3. **风险结构**：哪些未来事件或风险暴露可能使经营或估值假设失效，包括触发条件和可观察指标。

不得混写三个模块。不得把未来风险事件放进成本结构，不得把当前经营较弱换一种说法列作风险。完成三个模块后，只能在综合传导章节讨论它们之间的联系。

### 分离认知状态

对重要陈述使用以下标签：

- **事实**：已经发生并且能够核验；
- **推断**：对已知事实的解释；
- **预测**：对未来状态或事件的判断；
- **工作假设**：用于组织当前证据、可以修正或推翻的暂时解释；
- **未知**：缺少足够证据的重要问题。

不得用预测证明当前事实或当前估值结论。不得编造缺失的数值、来源、日期或引文。

### 保持可审计性

每项重要事实必须记录数值、期间或截止日期、统计口径和来源。优先采用公司公告、监管机构、交易所、官方统计和其他原始来源。二手研究主要用于解释和交叉验证；存在原始来源时，不得只用二手材料支持关键事实。

如果时效性信息可能实质改变答案，必须先核验再使用。

### 让结论可以被证伪

每个决定性结论必须给出：支持证据、反对证据或可信的替代解释、最大未知、增强判断的证据、削弱或推翻判断的证据，以及置信程度和理由。

所有结论都允许更新。出现新证据时，只更新受影响的因果链节点，并明确观点属于维持、小幅修正、明显修正还是推翻。

## 研究纪律

- 分析范围服从用户的问题，省略无关的可选章节。
- 行业、宏观和政策判断必须映射到公司收入、成本、风险暴露、现金流、ROE、ROIC 或资本成本。
- 情景分析必须写明假设和失效条件。优先给出可辩护的区间，不制造精确目标价。
- 区分低估值倍数和真正低估，反推当前价格隐含的经营假设。
- 可以分析利益相关方的激励，但没有证据时不得断言某个主体故意阻挠。
- 没有证据就明确说明未知，不用通用文字填补缺口。

## 写作纪律

删除角色扮演、情绪渲染、修辞性强调和模仿专业人士口吻的套话。只有不同证据确实形成竞争性解释时，才展示观点分歧，不进行虚构的多空辩论。

每个段落必须至少增加一种内容：事实、计算、因果关系、假设、反例、不确定性或验证条件。否则删除该段落。

结尾必须简要列出当前工作假设、置信程度、决定性未知、跟踪指标和改变结论的条件。
