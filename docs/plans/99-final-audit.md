# 实施前最终安全网审查

## 整体一致性

- 项目目标仍是单用户本地 K 线事件研究工具，没有把二期公司系统分析混入一期。
- 主流程从证券对象、行情、信息候选、人工确认、事件保存到图表投影保持一致。
- 路线只有一条依赖顺序：骨架 → 本地闭环 → 真实行情 → 图表 → 信息搜索 → Windows 发布 → 验收。

## 复杂部分覆盖

- 行情查询、缓存、主备源和冲突有独立设计与计划。
- 信息搜索、临时候选、重复提示和确认有独立设计与计划。
- 日期映射、周期聚合、同柱事件及双向定位有独立设计与计划。
- Windows 启动、迁移、恢复和发布有独立计划。
- 简单职责保留在路线图，没有隐藏多阶段实现。

## 跨边界流程

- 外部证券候选通过规范化身份进入研究目录。
- 外部行情先经适配、校验和合并，再进入缓存，UI 不接触来源格式。
- 信息候选只有经用户确认才转换为事件草稿并持久化。
- 事件真实日期与图表映射日期分离；投影只读、可重算。
- 事件与多对象关联、对象删除解关联和事件删除均有事务边界。

## 异常与恢复审查

| 路径 | 状态 | 处理 |
| --- | --- | --- |
| 验证失败 | Handled | 结构化问题，草稿或旧状态保留 |
| 行情部分成功 | Handled | 保存有效区间，WARNING 显示实际覆盖 |
| 重复输入 | Handled | 事件只提示；日线用唯一键保持幂等 |
| 外部超时 | Handled | 主源转备用，搜索可重试 |
| 用户取消/页面离开 | Handled | 旧页面响应不生效，未确认候选丢弃 |
| 重试耗尽 | Handled | 当前操作失败，保留本地有效数据 |
| 外部依赖不可用 | Handled | 行情显示缓存范围；搜索保留手工补录 |
| 数据损坏或版本不兼容 | Handled | 启动检查、迁移前备份、失败停止启动 |
| 降级模式 | Handled | 无备用源明确提示，不替换成近似指数 |
| 回滚与补偿 | Handled | SQLite 事务和迁移备份 |
| 重启恢复 | Handled | 持久数据恢复；会话和草稿允许丢失 |

问题合同使用 OBJECT、MARKET、SEARCH、DUPLICATE、EVENT、PROJECTION、STORAGE 分类；TIP/WARNING/EXCEPTION 决定继续策略和日志等级。领域层不拼 UI 文案，技术原因只进入本地日志。

## 扩展安全

- 没有插件、分布式消息、拦截器业务逻辑或后台队列需要额外治理。
- 行情与信息源通过端口和有序策略扩展；适配器不能写业务仓储。
- 进程内事件通知只刷新只读视图，失败后可重新加载，不影响事务事实。

- 免费行情和搜索源能否持续可用必须通过 M2/M4 探针验证；探针失败时回到用户审批，不能静默缩减或替换范围。
