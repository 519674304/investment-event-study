# 事件图表投影职责

## 目的

把已确认事件与当前 K 线序列组合成只读图表投影，使真实发布日期和图表落点同时可见。该职责不修改事件或行情。

## 公共合同

输入：`BarSeries`、与当前对象关联的 `ConfirmedEvent[]`、分类/标签过滤器。  
输出：`ChartEventProjection[]`，每项包含真实日期、图表映射日期、聚合组、简短标记和详情引用。

## 映射算法

1. 先按分类和标签过滤事件。
2. 对每个事件，在底层日线日期中寻找 `<= publishedOn` 的最大日期。
3. 没有此前日线时，不生成标记并返回 PROJECTION/TIP。
4. 日 K 直接使用该日期；周 K/月 K 映射到包含该日期的聚合行情条。
5. 同一周期行情条上的事件形成一个聚合标记，内部按真实日期倒序。

## 不变量

- 永远不修改 `publishedOn`。
- 非交易日不会被错误移动到未来交易日。
- 改变周期、时间范围或筛选器后投影可重复计算，不产生持久化副作用。
- 输出不包含自动领先/滞后、因果或投资结论。

## 边界和错误

- 事件超出当前图表范围：正常不显示，不是错误。
- 事件在首根可用 K 线之前：TIP，详情可保留但没有图上标记。
- 行情序列为空或无序：PROJECTION/EXCEPTION，拒绝生成投影。

## 测试边界

覆盖交易日、周末、长假、停牌、首根 K 线之前、同日多事件、周/月聚合、分类标签过滤及空行情。

## 备选方案

- 拒绝把映射日期写回事件：时间范围和行情修订会造成陈旧数据。
- 拒绝由 UI 临时查找此前日期：该业务规则应在可独立测试的职责中保持一致。
