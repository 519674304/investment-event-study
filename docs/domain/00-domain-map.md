# 领域总图

## 建模深度

采用轻量 DDD。项目存在清楚的业务概念和规则：研究对象唯一性、事件多对象复用、非交易日映射、搜索候选与已确认事件分离、缓存覆盖范围等；但它是单用户工具，没有复杂组织权限、资金交易或跨服务强一致性，不需要完整企业级 DDD。

## 整体业务地图

| 类型 | 上下文 | 业务目的 | 数据所有权 |
| --- | --- | --- | --- |
| 核心 | CTX-EVENT 事件知识 | 把用户确认的信息沉淀为可复用事件，并建立与研究对象的关系 | 事件、分类、标签、事件关联 |
| 核心 | CTX-MARKET 行情 | 为指定研究对象和时间范围提供可验证的 K 线序列 | 本地行情缓存、覆盖区间、行情来源记录 |
| 支撑 | CTX-CATALOG 研究目录 | 管理唯一研究对象及最后研究状态 | 研究对象、证券标识、页面状态 |
| 支撑 | CTX-DISCOVERY 信息发现 | 联网产生临时信息候选，供用户筛选 | 当前搜索会话；未确认候选不持久化 |
| 通用 | 外部免费数据适配 | 连接证券检索、行情和网页搜索来源 | 不拥有业务数据 |

## 参与者与外部系统

- 用户：唯一的事件确认者、编辑者和删除者。
- 免费证券检索源：返回股票、行业指数和概念指数候选。
- 主/备行情源：返回日线 OHLCV。
- 信息搜索源：返回标题、日期、来源、摘要和链接。
- 浏览器：呈现 K 线、事件标记和下方详情。

## 主流程

```text
用户选择或创建研究对象（CTX-CATALOG）
  -> 请求时间段行情（CTX-MARKET）
  -> 用户触发联网搜索（CTX-DISCOVERY）
  -> 用户编辑并确认候选
  -> 创建或关联事件（CTX-EVENT）
  -> 用行情日期生成事件图表投影（CTX-MARKET + CTX-EVENT）
  -> 浏览器显示 K 线、聚合标记和下方详情
```

## 上下文关系

- CTX-CATALOG 向其他上下文发布稳定的 `ResearchObjectRef`，不暴露内部页面状态。
- CTX-MARKET 接受 `SecurityIdentity + DateRange`，输出 `BarSeries` 和覆盖状态。
- CTX-DISCOVERY 接受对象快照和查询条件，输出临时 `InformationCandidate`；候选不能被其他上下文当作事件使用。
- CTX-EVENT 接受用户确认后的 `EventDraft`，保存 `ConfirmedEvent`，并通过对象 ID 建立多对多关联。
- 事件图表投影是应用协作结果，不把 `chartDate` 固化为事件本体属性；切换周期和时间范围时可以重新计算。

## 关键所有权决定

- 证券名称和代码的本地稳定身份由 CTX-CATALOG 所有；外部源返回的候选只是输入。
- OHLCV 真实性、去重和覆盖范围由 CTX-MARKET 所有。
- 搜索结果只由 CTX-DISCOVERY 在当前会话暂存，用户确认是候选进入事件知识的唯一入口。
- 事件真实日期由 CTX-EVENT 所有；图表映射日期由投影职责根据行情序列计算。
- UI 不拥有日期映射、重复提示和对象唯一性规则。

## 安全网审查

- 所有一期需求均映射到四个上下文和职责图。
- 没有共享数据库对象作为跨上下文合同；只通过稳定 ID 和值对象交换。
- 主备数据源是 Phase 4 的基础设施选择，不进入领域语言。
- 删除对象和删除事件属于不同一致性边界，避免级联误删。
