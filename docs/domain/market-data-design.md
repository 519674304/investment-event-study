# 行情上下文

## 目的与语言

在不预先同步全市场的前提下，为指定证券身份和日期区间提供完整、合法、带来源信息的日线序列，并由日线派生周线和月线。

核心术语：行情条、行情序列、覆盖区间、缺失区间、数据截止日、行情来源。

## 聚合与值对象

- 聚合根：`MarketSeries`，按证券身份管理缓存覆盖和日线条目。
- 实体：`DailyBar`，以交易日期唯一。
- 值对象：`DateRange`、`OHLCV`、`Coverage`、`MarketDataSourceRef`。

## 规则与不变量

- 同一证券和交易日期最多一条有效日线。
- `low <= open/close <= high`，成交量不能为负。
- 日期严格递增；外部重复记录在进入聚合前解决。
- 周 K、月 K 从已接受的日线聚合，不分别保存为事实源。
- 已缓存区间不重复请求；只补缺失区间或最新部分。
- 主源失败可降级到备用源，但来源冲突不得静默覆盖已有有效记录。

## 输出合同

`BarSeries` 包含证券身份、周期、实际首末日期、OHLCV、数据来源与缓存覆盖状态。它不包含事件或研究结论。

## 失败与补偿

- 外部源全部失败：返回结构化异常，保留原缓存。
- 部分区间成功：保存有效部分并返回警告及实际覆盖范围。
- 非法记录：跳过或中止取决于影响范围；不得传给图表。
