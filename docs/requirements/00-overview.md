# 一期需求总览

## 目的

研究者现在需要在行情图、新闻搜索和个人笔记之间反复切换，难以直观看到一条信息发布时，证券价格处于上涨前、上涨中还是上涨后。一期产品把“行情”和“已确认事件”按日期放在同一研究页面中，降低复盘成本。

产品只呈现可核对的时间关系，不自动给出因果关系或交易结论。

## 用户与利益相关方

- 主要用户：单个本地投资研究者。
- 数据提供方：免费的公开行情源、搜索结果及原始信息网站。
- 二期使用方：未来的公司系统分析模块，可复用一期积累的研究对象和事件，但不属于一期范围。

## 核心业务流程

1. 用户在首页按名称或代码查找 A 股股票、行业指数或概念指数。
2. 用户选择候选证券，创建或打开其唯一研究页面。
3. 用户选择起止日期和日 K、周 K 或月 K，系统联网补充缺失行情并绘图。
4. 用户点击“搜索信息”，系统以当前对象、时间段及可选附加关键词联网搜索。
5. 搜索结果按日期倒序分页，每页 20 条；系统提示可能重复项。
6. 用户勾选结果，在保存前编辑日期、标题、摘要、来源、分类、标签及关联对象。
7. 用户确认后，事件持久化并标记到所有关联对象的 K 线；未确认结果不保存。
8. 搜索遗漏的信息可手动补录。
9. 用户点击图上简短标记，下方详情区定位并高亮事件；点击下方事件，图表定位并高亮相应日期。

## 能力地图

| 能力 | 一期 | 二期或以后 |
| --- | --- | --- |
| 研究对象搜索与管理 | 是 | 扩展市场 |
| 按需行情查询与缓存 | 是 | 更多数据类型 |
| 日／周／月 K 切换 | 是 | 分钟 K |
| 联网信息搜索与人工筛选 | 是 | 自动采集与全文分析 |
| 手工补录事件 | 是 | 附件、全文归档 |
| 多对象复用同一事件 | 是 | 跨对象传导分析 |
| 图上事件标记与下方详情 | 是 | 自动领先／滞后判断 |
| 公司系统分析 | 否 | 二期 |

## 交付阶段

- 一期 MVP：完成本文档定义的单用户本地 Web 工具。
- 二期：公司盈利结构、成本结构、风险结构、行业传导与估值等系统分析；二期必须单独立项。

## 核心验收标准

- AC-CORE-001：能按名称或代码创建 A 股股票、行业指数、概念指数研究对象，并显示指定时间段的日／周／月 K。
- AC-CORE-002：能联网搜索信息、分页筛选、保存前编辑，也能手动补录。
- AC-CORE-003：一个事件可关联多个对象，并按规则标在 K 线上；非交易日映射到此前最近一根 K 线。
- AC-CORE-004：关闭并重新启动后，研究对象、行情缓存、已确认事件、分类标签和页面状态仍存在。

## 术语

- 研究对象：一只 A 股股票、一个 A 股行业指数或一个 A 股概念指数；每个对象只有一个持续积累的研究页面。
- 外部信息：联网搜索返回但尚未被用户确认的标题、日期、来源、摘要和链接。
- 事件：用户确认保存或手动补录的结构化关键信息。
- 事件真实日期：信息实际发布日期，始终保留并展示。
- 图表映射日期：事件标记落到的 K 线日期；没有同日 K 线时取此前最近一根 K 线。
- 行情缓存：已经查询并保存在本地的 OHLC 和成交量数据。
